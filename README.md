# 🚀 AgentGrid

> AgentGrid is an AI-powered multi-agent operating system that coordinates specialized AI agents to execute business workflows while keeping humans in control of important decisions.

AgentGrid converts high-level, natural language founder directives (such as hiring team members, modeling budget runway, launching marketing campaigns, or drafting legal agreements) into structured, multi-agent dependency graphs. It orchestrates specialized AI domain agents—**CEO, Finance, Marketing, Hiring, and Legal**—under a strict **3-Level Human-in-the-Loop (HITL) Governance model**, ensuring founders retain ultimate oversight and control over consequential startup decisions.

---

## ✨ Features

* **🧠 Dynamic CEO Task Decomposition & DAG Orchestration**  
  Ingests raw founder directives, extracts business entities (budget caps, role requirements, operational scope), and automatically structures step-by-step Directed Acyclic Graphs (DAGs) assigning task responsibilities across specialized domain agents.

* **🤖 Autonomous 5-Agent Domain Workforce**  
  * **CEO Agent**: Master orchestrator that analyzes directives, designs execution DAGs, coordinates agent communications, and enforces dependency ordering.
  * **Finance Agent**: Models runway impact, computes maximum burn rates, calculates target Customer Acquisition Cost (CAC), and approves stipend/budget ceilings.
  * **Marketing Agent**: Crafts multi-platform recruitment copy, founder launch threads, and social campaigns tailored for LinkedIn and Telegram.
  * **Hiring Agent**: Sources applicants, parses resume match scores, and builds candidate shortlists.
  * **Legal Agent**: Generates legally compliant startup documentation, including binding Internship Offer Letters, 100% Intellectual Property (IP) Assignment Agreements, and NDAs.

* **🛡️ 3-Level Human-in-the-Loop Governance**  
  * **Level A (Plan Approval)**: Founder reviews and approves the CEO's overall DAG execution strategy before agent execution begins.
  * **Level B (Result Approval)**: Founder inspects structured domain deliverables generated by agents before downstream dependencies are unblocked.
  * **Level C (Consequential Action Gate)**: Explicit founder authorization gate for external or irreversible operations (e.g., publishing posts live to LinkedIn/Telegram, dispatching DocuSign offer letters).

* **🎯 InterviewOS Sourcing & Code Execution Engine**  
  * **Automated Candidate Screening**: Computes weighted resume-to-job match scores based on required skills and experience years.
  * **Round 1 (MCQ Assessment)**: Auto-generates topic-specific multiple-choice questions with real-time test evaluation and score tracking.
  * **Round 2 (Live Sandboxed Coding IDE)**: Embedded code runner evaluating candidate submissions against test cases with custom input support, execution time caps (3.0s timeout), and stdout/stderr capture.
  * **Candidate Evaluation Matrix**: Generates a weighted composite score (Resume 20%, MCQ 30%, Coding 50%) and AI recommendations (`STRONG_HIRE`, `HIRE`, `RECONSIDER`, `REJECT`).
  * **Founder Hiring Gate**: Dedicated review page for founders to approve, reject, or request revisions on candidates.

* **📊 Live Dashboard & Audit Log Tracking**  
  Track active directives, running agent workloads, execution duration metrics, token consumption, and full audit logs detailing every orchestration, execution, and approval event.

* **🔐 Multi-Method Authentication**  
  JWT-based authentication with password hashing (bcrypt) alongside Google OAuth social login integration.

## 🎯 Problem

Building a startup requires founders to context-switch across legal, financial, marketing, and hiring tasks. While generative AI models can draft content, standalone AI chats lack context retention, dependency management, structured domain models, and safety guardrails against unintended autonomous actions (e.g., spending budget or dispatching offer letters without authorization).

---

## 💡 Solution

AgentGrid acts as an **autonomous executive suite with human governance**. It provides a single interface where founders state their objective in natural language. The CEO Agent plans the workflow, domain agents execute specialized tasks with upstream context, and the founder maintains control through multi-level approval gates before any consequential action is executed.

AgentGrid features deep AI integrations that handle business logic, classification, and deliverable generation:

| Feature | Input Context | AI Processing | Generated Output | Primary Model / Engine |
| --- | --- | --- | --- | --- |
| **Intent Classification** | Raw user text prompt | Intent routing & keyword/domain analysis | Intent domain classification (`CEO`, `HIRING`, `MARKETING`, `FINANCE`, `LEGAL`) with confidence score | Google Gemini API / Heuristic Engine |
| **DAG Decomposition** | Directive title & extracted entities | Business logic analysis & dependency mapping | Structured JSON `CEOPlan` containing steps, required agents, dependencies, and risks | Google Gemini API (`gemini-2.5-flash`) / Deterministic Orchestrator |
| **Financial Modeling** | Operational scope & budget cap | Runway burn modeling & salary benchmark analysis | Stipend ceilings, monthly runway impact, and CAC ad-spend limits | `FinanceAgent` + `MockFinanceService` |
| **Marketing Copy Generation** | Target role, stipend, & launch objective | High-converting copy generation | Ready-to-publish recruitment posts for LinkedIn & Telegram | `MarketingAgent` + `MockSocialAdapter` |
| **Assessment MCQ Generation** | Job title & required skill array | Technical question synthesis | 20 multiple-choice questions categorized by topic & difficulty | `HiringAgent` |
| **Coding Problem Generation** | Job title & target language | Problem specification & test case generation | Problem description, constraints, examples, starter code, and test cases | `HiringAgent` |
| **Candidate Evaluation** | Candidate scores (Resume, MCQ, Coding) | Weighted score synthesis (20/30/50 ratio) | Candidate report with overall score, strengths, concerns, and recommendation (`STRONG_HIRE`, `HIRE`, `RECONSIDER`, `REJECT`) | `HiringAgent` |
| **Legal Document Generation** | Selected candidate & stipend terms | Contract covenant formulation | Binding Internship Offer Letter & 100% IP Assignment Contract | `LegalAgent` + `MockDocumentService` |

## 🔐 Authentication & Security

* **User Registration & Login**: Built-in authentication endpoints (`/api/auth/register`, `/api/auth/login`) using Bcrypt password hashing (`passlib`) and OAuth2 password form handling.
* **JWT Token Security**: Generates signed JSON Web Tokens (JWT) using `HS256` with configurable expiration. Protected API routes enforce authentication via FastAPI's `get_current_user` dependency.
* **Google OAuth Social Login**: Integrates Google Identity Services SDK on the frontend and `/api/auth/social` on the backend to authenticate users via Google accounts.
* **Consequential Action Security**: Irreversible external actions (publishing social media posts or issuing legal offer letters) are gated behind explicit Level C founder authorizations and are never executed silently.

## 🗄️ Database

AgentGrid uses **SQLite** (or PostgreSQL via `psycopg2-binary`) with **SQLAlchemy ORM** for full persistence.

### Primary Entities & Models

* `User`: Stores user credentials, hashed passwords, full names, and social profile links.
* `Goal`: Tracks startup objectives, target dates, risk levels, and progress completion percentages.
* `Task`: Directive metadata, CEO plan JSON payloads, and lifecycle status (`DRAFT`, `CEO_ANALYZING`, `AWAITING_PLAN_APPROVAL`, `APPROVED`, `COMPLETED`, `REJECTED`).
* `Delegation`: Sub-tasks assigned to specific agents, order index, dependency arrays, context inputs, structured output JSON, available actions, and approval timestamps.
* `Approval`: Log of founder decisions for Level A, Level B, and Level C approval gates.
* `AuditLog`: Immutable system audit log entries recording all orchestration, execution, approval, revision, and consequential action events.
* `AgentActivity`: Activity feed logs rendered on the founder dashboard.
* `AgentTask` & `ExecutionLog`: Autonomous task records, execution time (in ms), and token usage metrics.
* `WorkflowDAG` & `PendingQueueItem`: Multi-agent DAG states and background queue items.
* `MemoryStore`: Context memory key-value store for domain agents.
* `Job`, `Candidate`, `AssessmentRound`, `MCQQuestion`, `CandidateMCQAnswer`, `CodingProblem`, `CodingSubmission`, `CandidateEvaluation`: Comprehensive database schema powering InterviewOS sourcing, testing, live coding evaluation, and candidate ranking.

## ▶️ Running AgentGrid

### Option 1: One-Click Windows Launcher (Recommended for Windows)

Run the root batch file to automatically start both the backend API and frontend dev server in background terminals and launch your browser:

```cmd
run_app.bat
```

Alternatively, to start the server directly:

```cmd
start_project.bat
```

### Option 2: Manual Terminal Startup

**Terminal 1 — Backend API Server:**

```bash
cd backend
# Ensure virtual environment is activated
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The FastAPI server will be available at `http://localhost:8000`. Swagger documentation is available at `http://localhost:8000/docs`.

**Terminal 2 — Frontend Dev Server:**

```bash
cd frontend
npm run dev
```

The React Vite application will open at `http://localhost:5173`.
